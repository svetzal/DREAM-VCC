The main table lists for each key code:

- The decimal value
- The mnemonic value
- The character represented;
- The character value.

In addition to the listed key codes, three more are meaningful:

- **CLEAR**
- **SHIFT**
- **BREAK**

moves forward one word; moves backward one word; **CTRL-U** toggles the shift-lock condition, suppressing the keystrokes for a character with a shift for a-z when in effect.

The CC310 module contains a table with 2 bytes for each keycode. The first byte is the scan code that the keyboard sends. Each entry lists the scan code to return for:

- (0) no shift key
- (1) shift key
- (2) control key

The key codes in the table mean:

- $00- $1F Returns that value.
- $20- $5F Returns the ASCII value.
- $60- $7F Returns that value.
- $80- $FF Returns that value.

The keyboard is configured to return a code which will map ASCII values. The table may be altered to return any possible keycode. Extended keycodes for null, enter, clear, break, and function keys are processed alphabetically.
